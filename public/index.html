BOT INTEGRATION

Hubungkan Bot ke VinzCloud API

Gunakan URL API dan API key dari server bot. Jangan taruh API key di frontend, GitHub, atau pesan bot yang bisa dilihat pengguna.

Node.js — SEND

Gunakan SEND_API_KEY dari environment bot untuk mengirim link.

const response = await fetch('https://vinzcloud.vercel.app/api/send-link', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'x-api-key': process.env.SEND_API_KEY
  },
  body: JSON.stringify({ email })
});
const data = await response.json();

Node.js — VERIFY

Gunakan VERIFY_API_KEY dari environment bot untuk verifikasi.

const response = await fetch('https://vinzcloud.vercel.app/api/verify-link', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'x-api-key': process.env.VERIFY_API_KEY
  },
  body: JSON.stringify({ email, magicLink })
});
const data = await response.json();

cURL — SEND

Cocok untuk tes API dari VPS/Pterodactyl.

curl -X POST 'https://vinzcloud.vercel.app/api/send-link' \\
  -H 'Content-Type: application/json' \\
  -H 'x-api-key: YOUR_SEND_API_KEY' \\
  -d '{"email":"user@example.com"}'

cURL — VERIFY

Untuk menguji endpoint verify secara langsung.

curl -X POST 'https://vinzcloud.vercel.app/api/verify-link' \\
  -H 'Content-Type: application/json' \\
  -H 'x-api-key: YOUR_VERIFY_API_KEY' \\
  -d '{"email":"user@example.com","magicLink":"PASTE_MAGIC_LINK"}'
